\title{車椅子卓球の打球精度に寄与する身体動作および筋活動の解析}
\etitle{Analysis of Body Kinematics and Muscle Activity Contributing to Shot Accuracy in Wheelchair Table Tennis}
\studentid{03-240351}
\author{明石 直也}
\supervisor{山下 淳 教授}
\abst{
  本研究は，身体機能の個人差が著しい車椅子卓球において，打球の正確性を決定づける生体力学的要因を解明することを目的とした．
  高速度カメラ，モーションキャプチャ，表面筋電図を用いた統合計測システムを構築し，決定論的モデルに基づき結果（着弾誤差）から原因（ラケット挙動・身体動作・筋活動）へと遡る階層的な要因解析を行った．
  機械学習（KNN，LSTM）および特徴量重要度分析（PFI）を用いた解析の結果，打球精度を直接支配する要因として，ラケット先端での打撃と一定の水平打ち出し角の維持が特定された．
  さらに，これらのラケット操作ミスを誘発する根本的な原因が，インパクトの瞬間ではなく，前打球からのリカバリー局面における体幹回旋の遅れにあることを明らかにした．
  本手法は，パラスポーツにおける個別最適化された科学的指導の基盤となるものである．
}

\section{序論}

\subsection{研究背景：一般化から個別最適化へ}
近年，パラリンピックへの社会的関心の高まりとともにパラスポーツの競技レベルは著しく向上しており，経験則のみならず科学的知見に基づいた指導への需要が急増している\cite{nakamori}．
従来のスポーツバイオメカニクス研究において，パフォーマンス向上のための指導指針を構築する最も標準的なアプローチは一般化であった．
これは，多数の熟練者の動作データを平均化し，万人に共通する理想的なフォーム（標準モデル）を導出する手法であり，健常者スポーツにおいては成功を収めてきた\cite{leesTechniqueAnalysisSports2002}．

一方，パラスポーツにおいては，競技の公平性を保つためにクラス分けが導入されているが\cite{tweedyInternationalParalympicCommittee2011}，これは身体操作の均質性を保証するものではない．
実際，Norouziらは同一の障害クラス内であっても，損傷レベル（完全・不全）の違いによって筋活動パターンに明確な差異が存在することを報告している\cite{norouziElectromyographicAnalysisElite2025}．
このように身体機能の極端な多様性が存在する状況下では，集団の平均モデルを適用することに限界があり，各選手固有の残存機能に立脚した個別最適化のアプローチが不可欠である．

\subsection{関連研究の課題と本研究の目的}
車椅子卓球に関する先行研究は増加傾向にあるが，その多くは動作のキネマティクス（フォーム）の記述や，特定条件下での単発動作の解析に留まっている\cite{yamMeasuringUpperLimb2021, zemkovaAssociationTrunkRotational2018}．
実際の試合で重要となる打球結果と，その駆動源である筋活動，および連続的なラリー動作の3者の関連性については，未だ十分な検討がなされていない\cite{ikenagaInfluenceBallImpact2020}．

そこで本研究では，車椅子卓球クラス4の選手を対象に，ラリー中の打球精度を決定づける要因を，ラケット・関節・筋肉の各階層において特定することを目的とする．
特に，機械学習（LSTM）と特徴量重要度分析（PFI）を用いることで，複雑な時系列データの中から，パフォーマンスに寄与する支配的な要因を抽出するフレームワークを提案する．

\section{提案手法}

\subsection{計測システム}
実験環境の概略を図\ref{fig:exp_setup}に示す．
実験参加者は車椅子卓球競技クラス4の選手1名とした．
計測には，光学式および映像式モーションキャプチャシステム，表面筋電計を使用した．
身体（上肢・体幹），ラケット，車椅子，およびボールの3次元位置座標を取得すると同時に，広背筋，大胸筋，上腕二頭筋，上腕三頭筋などの主要な筋群の活動電位を完全に同期して計測した．

\subsection{実験課題}
実験課題はコーチとのフォアハンドラリーとした．
実戦に近い状況を再現するため，コーチは参加者の近位（右側）と遠位へ交互に返球を行った．
参加者はこれらを対戦相手にとって返球が困難なコースであるターゲット（左端コーナー）へ，できるだけ早くかつ正確に打ち返すよう指示された．
本研究では，特に身体制御の難易度が高い近位での打球後の遠位での打球を解析対象とするため，打球位置が参加者の遠位となる打球動作を1試行と定義し，条件を満たす60試行を抽出して解析用データセットとした．


\subsection{解析アプローチ}
取得したデータに対し，以下の手順で階層的な要因解析を行った．

\begin{enumerate}
    \item \textbf{打球精度の定量化}:
    高速度カメラ映像から着弾位置を特定し，ターゲット中心からの距離 $D$ を算出して精度を定義した．
    \item \textbf{ラケット要因の特定}:
    打球時のラケット終端姿勢を入力，精度の高低を出力とする機械学習モデルを構築し，PFIを用いて精度識別に寄与する重要変数を抽出した．
    \item \textbf{身体・筋活動要因の解析}:
    特定されたラケット挙動を生成するために，どの局面の身体動作や筋活動が影響しているかについて，時系列解析を用いて検討した．
\end{enumerate}

打球の多くはターゲット周辺（青色）に集中しているが，一部に精度が低い試行（赤色）が散見された．
この精度のばらつきを生じさせる要因について，次項でラケット挙動の観点から解析する．

\subsection{ラケット挙動による精度決定要因}
k-近傍法（KNN）を用いた分類モデルにおいて，打球精度の識別率は72.5\%となり，ラケット挙動に成否の情報が含まれていることが確認された．
このモデルに対してPFI解析を行った結果を図\ref{fig:pfi_knn}に示す．

\begin{figure}[tb]
  \centering
  \includegraphics[keepaspectratio, width=0.9\linewidth]{chap3/pfi_score_knn_top10.png}
  \caption{打球精度判別に寄与するラケット変数の重要度（Top 10）}
  \label{fig:pfi_knn}
\end{figure}

図\ref{fig:pfi_knn}より，打球精度に最も強く寄与する変数は，\textbf{打球位置誤差（$\mathrm{Diff}_{\mathrm{Long}}$）}，\textbf{ラケット面角度（$\mathrm{Face}_{\mathrm{Vert}}$）}，\textbf{水平打ち出し角（$\mathrm{Launch\_Ang}_{\mathrm{Horz}}$）}の3点であった．
詳細な分析の結果，以下の傾向が確認された．

\begin{itemize}
    \item \textbf{打球位置:} 手元ではなくラケット先端（遠位）で打球した際に有意に誤差 $D$ が小さくなる．先端での打球の方がヘッドスピードを確保しやすく，かつ回転をかけやすいため軌道が安定したと考えられる．
    \item \textbf{打ち出し角:} 水平角60度付近を維持した試行で最も精度が高く，ここから逸脱すると精度が悪化する．
\end{itemize}

\section{考察}

\subsection{動作および筋活動による要因生成メカニズム}
前節で特定されたラケット先端での打撃や適切な角度維持を阻害する身体的要因について解析した結果，インパクトの瞬間そのものよりも，それ以前の準備局面に根本的な原因があることが示唆された．

具体的には，遠位打球後のリカバリー動作において，胸郭の回旋運動や広背筋の活動タイミングに遅れが生じた試行で，次弾の打球精度が低下する傾向が確認された．
クラス4の選手は下部体幹機能に制限があるため，上部体幹の代償動作でバランスを制御しているが，連続動作による疲労等でこのリカバリーが遅れると，結果として末端のラケット操作が不安定になり，手元での詰まった打球や角度ミスを誘発していると考えられる．

\section{結論}
本研究では，車椅子卓球選手のパフォーマンスを決定づける要因を，結果から原因へと遡るフレームワークによって解析した．
その結果，本被験者においては，ラケット先端での打球と一定の打ち出し角の維持が重要であり，その実現にはインパクト動作そのものよりも，打球間のリカバリー局面における体幹制御能力が支配的な役割を果たしていることを明らかにした．
本手法は，個々の選手の身体特性に基づいた課題抽出を可能にし，パラスポーツにおける個別最適化されたコーチングへの応用が期待される．
