\section{はじめに}
\label{sec:pmethod_introduction}

本章では，車椅子卓球選手の競技中の動作測定および解析のアプローチについて述べる．

\refsec{sec:approach}では，本研究の理論的枠組みである決定論的モデルの導入と，それに基づいた階層的な解析プロセス，および実験環境の概要について述べる．

\refsec{sec:variable_definition}では，解析の第一段階として，打球の正確性とラケットの終端姿勢の関係性を解明するための座標系・変数の定義，および画像計測と機械学習を用いた要因特定手法について述べる．

\refsec{sec:method_step2}では，特定されたラケット挙動を生成する身体的要因を明らかにするため，上肢および体幹の関節運動変数の定義と，ステップワイズ法を用いた解析手法について述べる．

\refsec{sec:analysis_EMG}では，動作の駆動源となる筋活動の信号処理および定性的な評価手法について述べる．

最後に\refsec{sec:pmethod_conclusion}では，本章のまとめを述べる．

\section{本研究のアプローチ}
\label{sec:approach}
本研究では，個人の身体機能差が著しい車椅子卓球選手において，打球の正確性を決定づける要因を解明することを目指す．従来のキネマティクス中心の解析や，単一時点の統計処理による一般化とは異なり，パフォーマンスから打球時のラケット操作，それを実現する関節運動，そして関節を駆動する筋活動という形で段階的に調べていく．

データの計測については，実際のラリー中における選手の身体動作と筋活動，およびその結果としての打球の正確性を同期計測する．
具体的には，計測された筋活動の時系列データを入力とし，打球の着弾誤差を出力とする機械学習モデルを構築する．このモデルは，インパクトの瞬間だけでなく，スイング開始前の準備局面を含む時間的な依存関係を学習する．さらに，学習済みモデルに対して Permutation Feature Importance（PFI）を適用することで，打球の成否に寄与する重要な筋群とその活動タイミングを定量的に特定する．
以上より，本研究では単なる動作観察では捉えきれない，パフォーマンスに直結する筋活動の時系列的な特徴を抽出し，客観的かつ説明可能な評価を行う．

本研究では，個人の身体機能差が著しい車椅子卓球選手において，打球の正確性を決定づける要因を解明することを目指す．そのための理論的枠組みとして，Chowら\citeen{chowUseDeterministicModels2011}がスポーツバイオメカニクス研究において推奨している決定論的モデルを採用する．
決定論的モデルとは，前章にて説明したように運動のパフォーマンスから遡り，それを力学的・物理的に決定づけるバイオメカニクス的要因を階層構造として分解および整理する手法である．Chowらは，パフォーマンス指標を恣意的に選択するのではなく，運動の結果とそれを構成する要因との間の理論的な結びつきを明確にすることの重要性を説いている．
本研究においては，このモデルに基づき打球動作を以下の階層構造で捉える．実際の試合は連続的なラリーによって構成されており，狙ったコースに正確に返球してラリーを継続する能力が勝敗を分けるパフォーマンスだと考えたため，モデルの最上位に設定するパフォーマンスの評価指標を相手へ返球を打球の正確性（打球の着弾点の目標からの誤差）と定めた．
この正確性を物理的に決定づける直接的な要因は，インパクトにおけるラケットの終端姿勢（位置，速度，角度等）である．さらに，このラケット挙動を生成する要因として上肢や体幹の関節運動が存在し，それらの運動を駆動する根本的な要因として筋活動が最下層に位置づけられる．
この階層構造に基づくデータを収集するため，図\ref{fig:exp_setup}に示す実験環境を構築した．
本環境では，実際のラリー中における選手の身体動作（モーションキャプチャで計測）と筋活動（表面筋電計で計測），およびその結果としての打球の正確性の同期計測を行う．ここで得られたデータを用い，以下の段階的なプロセスで解析を進める．

始めに，計測した画像の解析による打球位置と打球精度の計測として，以下の手順で計測およびデータ処理を行う．
解析手順は1）イベント区間の特定，2）ステレオ計測によるボールの3次元座標群の抽出，3）打球精度（着弾点の目標までの距離）の算出の3つの手順により構成される．


次に決定論的モデルの第1段階として，最上位の打球精度と直下のラケット終端姿勢の関係性を解析する．具体的には，ラケット挙動を表現する複数の変数を入力とし，打球精度を分類する機械学習モデル（k-近傍法，サポートベクターマシン，ランダムフォレスト）を構築する．構築したモデルに対して Permutation Feature Importance（PFI）を適用することで，ラケットの挙動において精度の良し悪しを決定づける重要な変数を特定する．

第2段階として，特定された重要なラケット変数を目的変数とし，その下層にある関節運動との関係性を解析する．ここでは，関節角度の時系列データを扱うために各関節の特徴量を用いた回帰分析を行い，ラケットの重要変数を生成するために支配的な関節運動を明らかにする．

最終段階として，特定された関節運動と最下層の筋活動との関連を調査する．ここでは定性的な評価を含め，主要な動作局面における筋活動レベル（平均振幅等）を確認し，動作の駆動源としての筋の役割を考察する．

以上により，本研究では決定論的モデルに基づく論理的な因果関係の枠組みの中で，結果から原因へと階層を掘り下げることで，パフォーマンスに直結する身体的要因を特定する．

\section{打球の着弾点とラケットの姿勢の解析}
\label{sec:variable_definition}
本節では，前節で述べた決定論的モデルに基づき、本解析で使用する座標系やラケット姿勢の変数の定義，打球精度を算出するためのデータ処理および打球の正確性とラケット姿勢の関係性を解析する手法を説明する．

\subsection{座標系の定義}
\label{subsec:coord_system}
本研究では，打球結果を物理的に決定づける要因を記述するために，2つの異なる座標系を導入する．
卓球におけるボールの軌道は，インパクトの瞬間にラケットとボールが接触する物理現象によって一意に決定される．
この現象を正確に紐解くためには，まずラケットが空間内のどのような姿勢で振られたかを記述するための世界座標系が必要となる． しかし，ラケットの空間的な動きだけでは，打球の質を完全に説明することはできない．
同じスイング軌道であっても，ラケット面上のどこでボールを捉えたかによって変化するためだ．このラケットの面上での位置関係を定量化するために，局所座標系としてラケット面上に座標系を設定する．
以上の観点から解析の基準となる座標系として，卓球台に固定された世界座標系と，ラケットに固定された局所座標系を定義した（図\ref{fig:spatial_coordinates}）．
世界座標系は，卓球台の中心を原点 $O_W$ とし，実験参加者から見て進行方向（ネット方向）を $X_W$ 軸，左方向を $Y_W$ 軸，鉛直上向きを $Z_W$ 軸と定義した．
また，ラケット局所座標系は，ラケットの重心位置を原点 $O_R$ とし，ラケット面の長軸方向（ラケット先端の方向）を $X_R$ 軸，面法線方向を $Y_R$ 軸，ラケット面の短軸方向を $Z_R$ 軸と定義した．

\subsection{実験課題とターゲット設定}
\label{subsec:bounce}

実験における課題設定にあたっては，単なる反復練習ではなく，実際の試合における勝敗に直結する実践的なラリーシチュエーションを想定した．
具体的には，実験参加者に対してクロス方向へのラリーを行わせる際，目標とする着弾位置を対角線上の最も遠い位置にあたる相手コートの左コーナーに設定した．
このターゲット設定は車椅子卓球特有の戦術的意図を考慮している．それは可動範囲に制限のある車椅子卓球において相手選手が取りにくい深く角度のついた位置にボールを送ることで，打球を困難にさせるという戦略である．
一方で，このようなコースを狙うことはわずかなコントロールミスによりアウトになってしまう可能性があるため，このコースを狙って打球を続けることは高度な打球精度が必要とされる．
その中で左コーナーに打球を行うために重要な要素を特定するために，以下の評価指標を定める．

本研究では実験参加者が打球を行う際の着弾の目標を上で定めたように左コーナーに設定し，実際のボールの着弾地点が目標からどれだけ離れているかの度合いを打球の正確性として定める．

打球の正確性を評価するため，着弾点の3次元座標を卓球台平面（$xy$平面）に投影し，目標の座標との平面距離を算出した．
試行 $i$ における着弾位置の水平座標を $(x_{\mathrm{land}}^{i}, y_{\mathrm{land}}^{i})$，目標とするターゲット位置の座標を $(x_{\mathrm{target}}, y_{\mathrm{target}})$ と定義する．
このとき，打球の誤差距離 $D_i$ は，以下の式に示す $xy$ 平面上でのユークリッド距離として定義される．
\begin{equation}
D_i = \sqrt{(x_{\mathrm{land}}^{i} - x_{\mathrm{target}})^2 + (y_{\mathrm{land}}^{i} - y_{\mathrm{target}})^2}  ，
\end{equation}
ここで，$D_i$ が $0$ に近いほど，目標に対して正確に着弾したことを意味し，値が大きいほどターゲットから逸脱した打球であることを示す．
本解析では，この誤差距離 $D$ の値を，後述するショットマップの色付けおよび機械学習モデルの出力変数として使用する．


\subsubsection{ステレオ画像計測による3次元座標の算出}
\label{subsubsec:stereo_measurement}

本研究では，打球の着弾位置およびラケットの空間位置を特定するために，複数台のカメラを用いたステレオ計測法を適用した．
この手法は，異なる視点から撮影された複数の2次元画像座標 $(u, v)$ を用い，三角測量の原理に基づいて対象の3次元空間座標 $(x, y, z)$ を復元するものである．

実際の打球データの算出にあたっては，以下の手順で画像座標の抽出を行った．
まず，各試行の録画映像から，解析対象となるインパクトおよび着弾に対応するフレームを特定した．
その後，計測開始前に実施したモーションキャプチャシステムのカメラキャリブレーションにて取得した各カメラの内部パラメータ（焦点距離，主点座標，歪み係数）および外部パラメータ（世界座標系におけるカメラの位置・姿勢）を用いて，これらを基に世界座標系からカメラ座標系への変換を記述する回転行列および並進ベクトルを算出した．
そして，整備したこれらのパラメータを用いて三角測量の原理に基づく3次元復元を行い，複数台のカメラによって撮影した画像から，対象空間におけるボールの3次元座標 $(x, y, z)$ を復元した．
最後に算出された着弾座標およびターゲット座標から，打球誤差 $D_i$ を算出した．

\subsection{ラケット姿勢変数の定義}
\label{subsec:racket_vars}
本項では，前項までの手法によって求めた打球誤差によって定められる，打球の正確性を直接決定づける要因であるラケットの終端姿勢を定量的かつ多角的に評価するため，以下の10個の変数を定義した（図\ref{fig:racketPos}）．
これらは全てボールがラケットに接触した瞬間の値を用いる．

\begin{enumerate}\item
  \textbf{ラケット位置 ($P_X, P_Y, P_Z$)}：世界座標系におけるラケット重心の3次元座標．
  \item \textbf{ラケット移動速度 ($|V|$)}：インパクト直前におけるラケット重心の移動速度の大きさ（スカラー量）．
  \item \textbf{打ち出し角 ($\theta_{Vert}, \theta_{Horz}$)}：インパクトの瞬間におけるラケットの移動方向を表す角度．世界座標系の進行方向（$X_W$軸）を基準とし，水平面内の偏角を\textbf{水平打ち出し角（$\theta_{Horz}$）}，鉛直方向への仰角を\textbf{垂直打ち出し角（$\theta_{Vert}$）}とする
  \item \textbf{ラケット面角度 ($\phi_{Vert}, \phi_{Horz}$)}：ラケット面の法線ベクトルが各方向となす角度．垂直方向の傾きを被せ角（$\phi_{Vert}$），水平方向の向きを面の左右角（$\phi_{Horz}$）とする．
  \item \textbf{インパクト位置誤差 ($\mathrm{D}_{\mathrm{Long}}, \mathrm{D}_{\mathrm{Short}}$)}：ラケット局所座標系における，ラケット位置から見たボール接触点のズレ．長軸方向の距離を $\mathrm{D}_{\mathrm{Long}}$，短軸方向の距離を $\mathrm{D}_{\mathrm{Short}}$ と定義する．これにより，重心近くで捉えられたかを評価する．
\end{enumerate}

\subsection{ラケット終端姿勢の重要変数特定}
着弾誤差距離（$D$）を直接決定づけるラケット変数を特定するため，機械学習モデルを用いた分類分析を行う．

まず，全試行を着弾誤差距離 $D$ の昇順（精度の良い順）に並べ替え，上位1/3試行を高精度クラス，下位1/3試行を低精度クラスと定義した．
なお，中間となる残りの試行は，クラス間の特徴差を明確にするため解析対象から除外した．

本解析における機械学習モデルの入出力構造を\ref{tab:ml_dataset}に示す．
入力変数には，前項で定義したインパクト時のラケット位置・速度・角度などの運動学的パラメータ（計10変数）を用い，出力変数には上記の2値クラス（高精度／低精度）を用いた．
構築したデータセットに対して，打球動作と精度の間の非線形関係を捉えるために，非線形分類が可能なアルゴリズムであるk—近傍法（kNN），サポートベクターマシン（SVM），およびランダムフォレスト（RF）の3手法を採用して比較検証を行った．
本解析では，これらの手法の中で最も高い識別精度を示したモデルを選定し，要因解析のベースモデルとして使用した．
さらに学習済みモデルにおいて，どの変数が分類に大きく寄与しているかを定量化するために，Permutation Feature Importance（PFI）を適用し，各変数につき100回のシャッフル試行を行い，その際の精度低下量の平均値を各変数の重要度として算出した．
この手法を用いることで，打球精度に影響を与える物理的要因を抽出することが可能となる．

\section{ラケットの姿勢と関節運動の解析}
\label{sec:method_step2}
本節でも引き続き，\ref{sec:approach}節で述べた決定論的モデルに基づき，ラケットの終端姿勢を生成する関節運動の変数を定義し，ラケット姿勢と関節運動の関係性を解析する手法を説明する．
\subsection{関節運動変数の定義}
\label{subsec:joint_vars}
ラケットの終端姿勢を生成する身体的要因として，上肢および体幹の関節角度を定義した．ただし，手首の関節に関しては計測は出来ていたものの、データの欠損により十分な試行数が確保できなくなるので、本研究においては取り扱わない．
本研究では，車椅子卓球における打球動作への寄与が大きい以下の関節運動に着目する（図\ref{fig:def_shoulder}）．

一般的な打球動作において，運動エネルギーは体幹部から末端部へと順次伝達される．
特にフットワークや股関節による並進運動が制限される車椅子卓球選手においては，固定された骨盤上の体幹回旋が運動連鎖の始動点となり，
肩や肘関節がそのエネルギーを増幅してラケットを加速させる役割を担う．
したがって，手首を除くこれら体幹から肘までの関節群こそが，スイングの軌道生成とパワー発揮を決定づける主要因であると考え，以下の自由度を定義した．

\begin{itemize}
 \item \textbf{肘関節}：屈曲・伸展および回旋の2自由度．
 \item \textbf{肩関節 （Shoulder）}：屈曲・伸展，外転・内転，内旋・外旋の3自由度．
 \item \textbf{体幹 （Trunk）}：胸郭と骨盤の間の相対角度として算出される，屈曲・伸展，側屈，回旋の3自由度．
\end{itemize}

\subsection{関節運動の解析手法}
\label{subsec:joint_analysis}
本節では，前節までの手法で特定される打球を左右する重要なラケット挙動が，どのような身体動作によって生成されるかを解析する手法について説明する．

\subsubsection{特徴量の設計と運動学的意義}

関節運動の時系列データは情報量が膨大であるため，単に全ての時刻の値を解析に用いることは現実的ではない．
そこで本研究では，単なる関節の曲げ伸ばしだけでなく，選手が持つ動作特有のリズム，キレ，運動連鎖といった質的な要素を定量化するために，以下の4つの観点で計136個の特徴量を定義した．
算出対象は，体幹および上肢（肩，肘）の各自由度である．
\begin{description}
  \item[単体動作の「大きさ・形」 (32変数)] \mbox{}\\
  フォームの空間的な広がりを評価する指標．
  \begin{itemize}
    \item $\mathrm{\theta_{Imp}}$: インパクト瞬間の角度
    \item $\mathrm{\theta_{Max}}$: スイング中の最大角度
    \item $\mathrm{\theta_{Min}}$: スイング中の最小角度
    \item $\mathrm{\theta_{ROM}}$: 可動域 ($\mathrm{\theta_{Max}} - \mathrm{\theta_{Min}}$)（スイングのダイナミックさ）
  \end{itemize}

  \item[単体動作の「速さ・強さ」 (24変数)] \mbox{}\\
  動作の勢いやスピードを評価する指標．
  \begin{itemize}
    \item $\mathrm{V_Imp}$: インパクト瞬間の角速度
    \item $\mathrm{V_Max}$: 前方への最大角速度
    \item $\mathrm{V_Min}$: 後方への最大角速度
  \end{itemize}

  \item[単体動作の「時間・キレ」 (24変数)] \mbox{}\\
  筋肉のバネ特性やリズムを評価する指標．
  \begin{itemize}
    \item $\mathrm{T_{PeakPos}}$: 最高速度に達した時刻
    \item $\mathrm{T_{PeakNeg}}$: 最速で引ききった時刻
    \item $\mathrm{T_{Duration}}$: 切り返しの所要時間
  \end{itemize}

  \item[連動性・ラグ (56変数)] \mbox{}\\
  運動連鎖の適切さを評価する指標．2つの関節運動間の時間差を算出．
  \begin{itemize}
    \item $\mathrm{T_{LagPos}}$: 各特徴量の正方向のピーク時間差
    \item $\mathrm{T_{LagNeg}}$: 各特徴量の負方向のピーク時間差
  \end{itemize}
\end{description}

\subsubsection{ステップワイズ法による変数選択}
前項の定義により，合計136個の説明変数が用意された．
この全ての特徴量を一度に重回帰モデルに投入した場合，変数の数に対してサンプル数が不足して，モデルが学習データのノイズまで適合することで過学習のリスクが極めて高くなってしまう．
そこで本研究では，Hockingらによる変数選択手法であるステップワイズ法を適用する．
この手法はモデルの予測精度に寄与する重要な変数のみを逐次的に追加，削除していくことで重要な変数に絞っていくアルゴリズムである．
これにより，膨大な特徴量候補の中から，ラケット挙動に対して支配的な影響を持つ少数の身体動作要因を抽出することが可能となる．

\section{おわりに}
\label{sec:pmethod_conclusion}

本章では，車椅子卓球選手の打球精度を決定づける要因を解明するための実験系および解析手法について述べた．

\refsec{sec:approach}では，打球精度からラケット挙動，関節運動，筋活動へと遡る決定論的モデルに基づく解析の全体像を示した．

\refsec{sec:variable_definition}では，ステレオ画像計測による3次元座標復元と打球誤差の定義を行い，機械学習（k-近傍法）およびPermutation Feature Importance（PFI）を用いて，打球精度に寄与するラケットの重要変数を特定するプロセスを説明した．

\refsec{sec:method_step2}および\refsec{sec:analysis_EMG}では，ラケット挙動を生成する身体メカニズムにアプローチするため，136個の関節運動特徴量を用いたステップワイズ法や，筋活動の解析手順について記述した．

次章では，これらの手法を用いて得られた実際の解析結果を示し，決定論的モデルに従い車椅子卓球選手の打球精度に寄与するラケット挙動，関節運動，筋活動について階層的に考察する．
